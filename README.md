# The Day in News — 20 November 2026

A make.fun bounty entry: [news-image-20261120](https://make.fun/bounty/news-image-20261120)

`main.py` (pure Python 3 standard library, no network) draws one 1024×1024
PNG that sums up the world news of Friday 20 November 2026 — a broadsheet
front page with six stories, each verified against reporting published
that day:

1. **Markets tumble on AI jitters** — Nikkei −4.8%, dollar near a
   19-month high (Reuters, 20 Nov)
2. **Houthi missiles hit Riyadh tower** — the PIF tower damaged, a
   tanker burns near Hormuz, oil climbs (Reuters, 20 Nov)
3. **UK sends 1,000+ drones to Ukraine** — £260M package as Europe
   readies new peace talks (20 Nov)
4. **Taiwan flags 2,700 accounts** — China-linked accounts reported to
   Meta ahead of the 28 Nov elections (Reuters, 20 Nov)
5. **COP31 final day in Antalya** — fossil fuels cut from the draft
   deal (Reuters / Le Monde, 20 Nov)
6. **GTA VI sells 24.6M on day one** — an estimated $2.36B, the biggest
   entertainment launch ever (Sensor Tower via BBC, 20 Nov)

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Two runs produce byte-identical output (`entry.png`, ~15 KB).
